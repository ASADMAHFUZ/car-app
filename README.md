# AutoPlaza.ch

Mobile-first React UI for the AutoPlaza / Maaholi car marketplace: home screen, bottom navigation, and Search destinations screen.

## Run locally

1. Install [Node.js](https://nodejs.org/) (LTS).
2. Install dependencies: `npm install` (or use the vendored `node_modules` if present).
3. Build: `npm run build` (requires `esbuild` on PATH, or place `esbuild.exe` in `.tools/`).
4. Serve: `npm run dev` → open [http://127.0.0.1:5173/](http://127.0.0.1:5173/).

## Stack

- React 19
- Vite-style layout (`src/App.tsx`, assets under `src/assets/`)
